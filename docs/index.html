Free & open source · Windows 10 and 11

Your folders and servers, one click away.

Shellman is a Windows terminal manager built around the places you work. Save a project folder with a startup command like claude or npm run dev, or an SSH or Telnet host, then open it in a tab or split with one click.

Download for Windows View source on GitHub

2 MB installer · no admin rights needed · updates itself

Everything you open, in the place you expect it

Most terminals start in your home folder and forget everything when you close them. Shellman remembers where you work.

Saved sessions

A session is a folder plus an optional command, shell, colour and environment variables, or a remote host. Group them by client or project, and your tabs and splits reopen where you left them.

SSH and Telnet

Save hosts next to your folders, or just type user@host to connect without saving. Your keys, 1Password or the Windows ssh-agent and ~/.ssh/config work as usual. Pick a key per host, log in with a password, or allow old algorithms for old gear.

A tree of open terminals

Every session lists the terminals running in it. Click one to jump to its tab, even with twenty tabs open. Collapse what you don't need.

Any shell, any time

PowerShell 7, Windows PowerShell, Command Prompt, Git Bash and WSL are found automatically. Open a session in another shell, or switch a running terminal from the status bar.

Tabs and splits

Split right or down to any depth, drag dividers, maximise a pane, move focus with Alt+arrows. New tabs and splits start in the current terminal's folder.

Made for Claude Code

Every Claude tab keeps its own conversation and gets it back after a restart. Shift+Enter for newlines, Ctrl+V pastes screenshots, and the tab lights up when Claude finishes or needs input.

Quick open

Ctrl+Shift+P fuzzy-searches your sessions, or connects to a host you type. Enter opens a tab, Ctrl+Enter splits right, Shift+Enter splits down.

Small, fast, up to date

Written in Rust with Tauri, on Windows' own ConPTY: a 5 MB app with GPU-rendered terminals. Signed updates download in the background and install on the next restart.

Questions

Is Shellman free?

Yes. It's free and open source under the MIT license. The code is on GitHub.

Do I need Claude Code to use it?

No. Shellman works with any shell or command. Claude Code gets some extras: Shift+Enter newlines, pasting images, and a flashing taskbar when Claude finishes or needs input.

Which shells are supported?

PowerShell 7, Windows PowerShell, Command Prompt, Git Bash and WSL are detected automatically. You can add any other shell in Settings.

Can I use it for SSH and Telnet?

Yes. Save hosts next to your folders, or connect without saving by typing user@host in quick open. Shellman runs Windows' own OpenSSH client, so your keys, the Windows ssh-agent or 1Password's SSH agent, ~/.ssh/config and known_hosts work as in any terminal. With many keys in an agent, pick each host's key so servers don't give up after six tries. Telnet uses the Windows Telnet Client, an optional Windows feature.

Does Shellman store my passwords or SSH keys?

No. ssh asks for passwords in the terminal, and private keys stay in your key files or SSH agent. For a key you pick from the agent, Shellman keeps only its public half, so ssh knows which key to ask the agent for.

How do updates work?

Shellman checks for new versions in the background, downloads them and installs them the next time you restart it. Updates are signed. In Settings you can switch to notifications only or turn checks off.

Why does Windows SmartScreen warn about the installer?

The installer isn't signed with a paid code-signing certificate yet, so SmartScreen asks you to confirm. Choose More info, then Run anyway. You can read the source code and build it yourself.

Where are my sessions stored?

In %APPDATA%\app.shellman.desktop\config.json on your own machine. Every save keeps the previous version as a backup. Nothing is sent anywhere.
